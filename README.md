# Coffee Shop Sales Analysis Dashboard

# Overview

This project analyzes coffee shop sales transactions across multiple store locations using **Microsoft Excel**.

The objective of this project was to identify:

* Revenue trends
* Customer purchasing behavior
* Peak business hours
* Product category performance
* Store-wise sales insights
* Monthly growth patterns

An interactive dashboard was built using:

* Pivot Tables
* Pivot Charts
* Slicers
* KPI Cards
* Dynamic Excel Visualizations

The dashboard helps businesses make data-driven operational and sales decisions.

# Business Problem

Coffee shops process thousands of transactions daily, making it difficult to manually track:

* Revenue performance
* Customer footfall
* Product demand
* Peak sales timings
* Store-wise trends
* Category-wise sales contribution

This project solves the problem by converting raw transactional data into an interactive business intelligence dashboard.

# Objectives

* Analyze sales performance across locations
* Track customer footfall trends
* Identify high-performing products
* Understand hourly purchasing behavior
* Build an interactive Excel dashboard
* Generate business recommendations

# Key Business Insights

## Sales Insights

* Coffee contributed 38.6% of total revenue
* Morning hours (8–10 AM) generated the highest sales
* Thursday recorded the highest customer footfall

## Customer Insights

* Customer purchasing activity was highest during morning hours
* Revenue patterns varied across store locations
* Certain product categories consistently outperformed others

## Operational Insights

* Peak hour staffing optimization is necessary
* Inventory planning should focus on top-selling products
* Targeted weekday promotions can improve sales performance

# Business Recommendations

* Increase staffing during peak morning hours
* Promote high-margin coffee products
* Optimize inventory for top-selling categories
* Introduce loyalty programs for repeat customers
* Launch weekday promotional campaigns
